# Cách sử dụng

## 🗂️ Duyệt theo chủ đề

Nhấn vào tab trên thanh điều hướng để chọn chương, sau đó chọn câu chuyện từ thanh bên trái.

---

## 🔍 Tìm kiếm

Nhấn biểu tượng 🔍 ở góc trên phải (hoặc nhấn tổ hợp phím Ctrl+K) để tìm theo:

- **Tên nhân vật** — ví dụ: `Marie Curie`, `Bạch Thái Bưởi`
- **Từ khóa nội dung** — ví dụ: `kiên nhẫn`, `sáng tạo`, `hy sinh`
- **Tên quốc gia** — ví dụ: `Việt Nam`, `Mỹ`, `Ý`

---

## 🏷️ Lọc theo tag

Mỗi câu chuyện được gắn **tags** để dễ lọc. Gõ tag vào ô tìm kiếm:

| Tag | Ý nghĩa |
|-----|---------|
| `kientri` | Kiên trì, nghị lực |
| `dungcam` | Dũng cảm, bản lĩnh |
| `khiemton` | Khiêm tốn, cầu thị |
| `trungthuc` | Trung thực, chính trực |
| `hysinh` | Lòng nhân ái, hy sinh |
| `kyluat` | Ý chí, kỷ luật bản thân |
| `sangtao` | Sáng tạo, tư duy đột phá |
| `nghiluc` | Nghị lực vượt khó |
| `daoduc` | Phẩm hạnh, đạo đức |
| `tritue` | Trí tuệ, tư duy |
| *(tên nhân vật)* | ví dụ: `hochiminh`, `billgates` |
